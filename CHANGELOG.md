## Changelog - v1.2
     
### New Features

**Template Management**
- Create and manage up to 20 custom templates for formatting PR links
- Switch between different templates to use your preferred format
- Customize both plain text and HTML output formats
- Templates support variables: organization, repository, PR number, title, URL, and 
display name
- Default template cannot be deleted

**Auto-sync between Plain and HTML**
- Plain text automatically converts to HTML format
- Markdown-style links automatically become clickable HTML links
- Option to manually edit HTML or reset to auto-sync

**Live Preview**
- See how your PR link will look before copying
- Preview updates based on current page and active template

### Visual Improvements
- Improved button designs
- Enhanced form labels and styling
- Better icon visibility
